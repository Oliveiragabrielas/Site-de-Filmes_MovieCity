##  Sobre

O **MovieCity** é um projeto acadêmico que apresenta uma página dedicada ao universo dos filmes, com imagens, componentes reutilizáveis e uma interface adaptável a diferentes dispositivos.

##  Tecnologias

-  **React** — criação de componentes e interface.
-  **JavaScript** — funcionalidades da aplicação.
-  **CSS3** — estilos e responsividade.
-  **Vite** — ambiente de desenvolvimento.

##  Instalação e execução

Clone o repositório e acesse a pasta do projeto. Em seguida, execute:

```bash
npm install
npm run dev
```

Acesse o endereço local exibido no terminal para visualizar a página.
